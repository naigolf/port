# Naigolf - Developer Portfolio 🚀

Portfolio รวบรวมผลงานการพัฒนาซอฟต์แวร์, บอทเทรด Algorithmic Trading (MT5), ส่วนขยาย Chrome Extensions, ระบบ Automation & RPA (n8n), โครงงาน IoT / Hardware (ESP32-S3, Xiaozhi AI Voice, KidBright) และ Linux Server Modding รวมทั้งหมด **21 โปรเจกต์**

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (Project Files)

- `index.html` : หน้าหลักของ Portfolio รวมการ์ดโปรเจกต์ 21 รายการ พร้อมระบุภาษาและเทคนิค
- `css/style.css` : สไตล์ Dark Mode, Cyber Glow, Glassmorphism
- `js/main.js` : ระบบค้นหาแบบเรียลไทม์, แยกหมวดหมู่, Modal Deep Dive และ Lightbox
- `images/` : โฟลเดอร์เก็บรูปโปรไฟล์ (`profile.jpg`) และรูปภาพโปรเจกต์ (`projects/`)
